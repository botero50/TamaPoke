🐢 TamaPoke Fun Pack

A tamagotchi with hundreds of Pokémon for the Waveshare ESP32-S3-Touch-AMOLED-1.75. Install it from your browser — no Arduino, no drivers.

⚠️ Your browser doesn't support Web Serial. Use Chrome or Edge on a computer.

⚠️ Board not showing up? Read this first — it is almost always this.

A brand-new board does not appear as a serial port at all. The firmware it ships with never switches USB on, so your computer sees nothing and it looks like a dead board or a broken cable. It is neither. Put it in download mode:

hold BOOT → tap RESET → let go of BOOT

The two small buttons next to the USB-C socket. Nothing on screen will change — that is normal. Now press install and the port will be there. After TamaPoke is on it, this is never needed again.

Still nothing? Use a cable that carries data (a charge-only USB-C cable powers the board perfectly and carries nothing), and plug straight into your computer rather than through a hub.

💾Save or restore your pet

Use Save my pet before an update: it downloads a small file of your creature, Pokédex, coins and items, after checking that the file is complete. If anything goes wrong, Restore my pet puts it all back. New board? Skip this.

Pick the board's port when asked. Close any other tab or program using the board first: only one can use the port at a time.


  


  
📶Optional: Wi-Fi for the real time and the weather

  

    
The board's clock has no battery of its own, so it forgets the time when the
       power runs out. With your Wi-Fi it sets the time from the internet by itself
       (every few hours, for a few seconds) and can show the weather outside: grey
       skies, rain, snow and the temperature. Do this after installing.

    

      
      
    

    

    

    

      
      
    

    
Only 2.4 GHz networks work (the board has no 5 GHz radio). The
       password stays on the board: it is not in Save my pet backups and is not
       sent anywhere else. The weather comes from
       Open-Meteo, which gets only the rounded
       location.

    

  


  
1Flash the firmware

  

    
Plug the board in via USB and press Install now. Pick the port when
       asked. The install takes about a minute, with no drivers on any OS. Updating a
       board that has a pet? Press Save my pet in the section above first. A
       new board, or one running something else, has nothing to save. If you have not
       saved on this page, tick the box below first.

    

    
Tick the box above first. Updating does not erase the pet; this is only a safety net.

    
      
      Browser not supported (use Chrome/Edge).
      Needs HTTPS.
    
    

       🔄 Updating? Leave "Erase device" unchecked. The installer asks
       once, with the box already unchecked — click Next without ticking
       it and your creature, Pokédex and badges all survive, because the
       firmware is written around the save rather than over it. Tick that box
       and everything is gone, with no undo. The sprites on the microSD are
       untouched either way.


       Installers before v2.7 erased it every time, without asking.
       They shipped one image covering the whole start of flash, the save
       included, and were configured to wipe the chip before writing. Both are
       fixed here. Even so, a backup is the only real safety net, which is why
       Save my pet is there (it is the same as typing EXPORT on
       the serial console).


       A fresh board with nothing on it can be erased safely, and on a board
       that has never run TamaPoke it makes no difference either way.

  


  
2Load the sprites onto the microSD

  

    
Put a microSD into the board (it formats itself). Press Connect board,
       then a region. Any one of them works on its own — pick Johto or Hoenn if
       that is the game you want — and the others can be added later without
       redoing this one. Kanto is simply the usual place to start.

    
⏱️ This part is slow, and that is normal. The sprites go over
       the USB serial link, so Kanto's 40 MB takes roughly 10–15 minutes. Leave the
       tab open and the card in. The progress bar moves the whole time.

    
Close the step-1 install tab first (only one program can use
       the port at a time).

How to play

  
Care for your egg until it hatches, feed it, play, train it and complete them
     all. Tap the creature to pet it; swipe to open the Pokédex (sideways), the
     stat card (up) or set the clock (down); the physical PWR button turns the
     screen off (short press) or everything off (long press).
     More in the repository.
